# 02 — Internationalization (i18n)

## Goals

1. **Originality preservation.** The text in the source language is the
   ground truth. Translations are derived artifacts and must be marked
   as such.
2. **Multiple languages per entity.** No statement is locked to one
   language; an entity may carry English, Spanish, French, German, etc.
3. **Translation provenance.** A reader (or an audit) must be able to
   tell whether a given translation was written by a human, generated by
   an LLM, or imported from another source — and whether it has been
   reviewed.
4. **The original is never lost.** Even if a translation is corrected,
   the original-language entry remains the canonical formulation.

## Shape

A multilingual block is a mapping from `LangCode` (`en`, `es`, `fr`,
`pt-BR`, …) to `TranslatedText`:

```yaml
title:
  en:
    text: Intermediate Value Theorem
    is_original: true
    origin: original
    review_status: approved
  es:
    text: Teorema del valor intermedio
    is_original: false
    origin: llm
    generated_by: "llm:claude-opus-4.7"
    review_status: unreviewed
```

## Invariants

- Every multilingual block must contain **at least one** entry.
- **Exactly one** entry must have `is_original: true`.
- The language declared in `language.original` at the top of the entity
  must be present and `is_original: true` in `title` and
  `statement.natural` (and in `sketch` for proofs, when present).

These are enforced by `schema/v03.py` and re-checked by
`scripts/v03/validate.py`.

## Translation lifecycle

| `origin`    | Meaning                                              |
|-------------|------------------------------------------------------|
| `original`  | This is the source-language text from the textbook.  |
| `human`     | Translated or written by a human contributor.        |
| `llm`       | Generated by a language model. Set `generated_by`.   |
| `imported`  | Imported from another structured source / library.   |

`review_status` follows: `unreviewed → reviewed → approved | rejected`.

A translation may be replaced (its `text` rewritten), but `is_original`
must never migrate to a different language. To "re-anchor" originality
(e.g., the project decides to canonize an English version) requires
explicitly creating a new entity, not editing the flag.

## Source language vs entity language

- `language.original` records the language of THIS entity's source
  material.
- `Source.source_language` records the language of EACH source citation
  individually.

These can differ when an entity merges sources in different languages
(e.g., a Spanish Stewart citation and an English Rudin citation under one
node where the original-language text is English Rudin).

## Why is_original is per-block, not per-entity

`title` and `statement.natural` may have different originality histories.
A Spanish-language source may carry an originally English title because
the publisher imported the title verbatim. The schema therefore tracks
originality per multilingual block.
